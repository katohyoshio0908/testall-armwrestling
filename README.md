# 加藤 ARM（プロトタイプ）

アームレスリングの **大会成績・選手成績・対戦結果を動画付きで確認できる** サイトの原型です。
ビルド不要の HTML / CSS / JavaScript だけで動きます。

## 起動方法

`start.bat` をダブルクリック → ブラウザで http://localhost:8080/ が開きます。

- PowerShell で手動起動する場合: `powershell -ExecutionPolicy Bypass -File serve.ps1`
- `index.html` を直接開いても動きますが、YouTube 埋め込みは `file://` だと再生できないことがあるため、サーバー経由を推奨します。

## 大会形式

| 形式 | 流れ | 試合区分 |
| --- | --- | --- |
| トーナメント（`double`） | 本戦 → 敗者復活戦 → 決勝。敗者復活戦の勝者が決勝1回戦目を制した場合のみ決勝2回戦目 | 本戦 / 本戦決勝 / 敗者復活戦 / 敗者復活戦決勝 / 決勝 / 決勝2回戦目 |
| リーグ戦（`league`） | 総当たりの予選リーグ（サークル方式の対戦順）→ 上位2名で決勝 | 予選 / 決勝 |

- 最終順位は上位3名のみ表示します（トーナメント: 決勝の勝者・敗者と敗者復活戦決勝の敗者 / リーグ戦: 決勝の勝者・敗者と予選の次点）。
- リーグ戦の順位は 勝数 → 直接対決 → ピン勝ち数 → シード順 で決まります（[js/rules.js](js/rules.js)）。

## 画面構成（ハッシュルーティング）

| URL | 内容 |
| --- | --- |
| `#/` | ホーム：最新大会の優勝者、最近の試合、試合動画 |
| `#/tournaments` | 大会一覧 |
| `#/tournaments/:id?c=階級&arm=R\|L` | 大会結果：トーナメント表 / リーグ表（各試合をクリックで試合ページへ）、上位3名（写真付き）、大会動画、試合一覧 |
| `#/athletes` | 選手一覧：名前・あだ名・チームでの検索、階級・参加腕での絞り込み |
| `#/athletes/:id` | 選手詳細：顔写真、あだ名、利き腕（右/左/両）、大会ごとの計量体重と順位、通算成績、試合履歴 |
| `#/matches` | 試合一覧：大会・階級・腕・試合区分・動画有無で絞り込み |
| `#/matches/:id` | 試合詳細：動画、勝敗・決着方法・試合区分、両選手の計量体重 |
| `#/h2h?a=:id&b=:id&arm=R\|L` | 対戦比較：選手を検索して選択、両腕/右腕/左腕で切替 |

## ファイル構成

```
index.html          レイアウト（ヘッダー/フッター）
css/style.css       スタイル（ライト/ダーク両対応・レスポンシブ）
js/rules.js         競技ルール（シード配置・リーグ順位）
js/data.js          データ（階級・試合区分・選手・大会・計量体重・出場者）
js/sample-gen.js    サンプル用の試合結果自動生成（実データを入れたら削除可）
js/store.js         データアクセス層（集計・順位・検索など）
js/app.js           画面描画とルーター
img/athletes/       選手の顔写真（サンプルはイラスト。同名のjpg等に差し替え可）
serve.ps1           ローカル確認用の簡易サーバー
```

## データの入れ方

- **選手**: `athletes` に追加。利き腕・階級・体重は大会の出場記録から自動判定するので入力不要です。写真は `photo` にパスを指定します。
- **大会**: `weighIns` に計量体重、`divisions` に部門（階級×腕）ごとの形式と出場者（シード順）を書きます。
- **試合結果**: 各 division の `matches` に書きます（形式は data.js 冒頭のコメント参照）。`matches` を省略した部門は sample-gen.js がサンプル結果を作ります。
- 不戦（シード）で試合がない回戦は自動で詰めて表示します。

## 動画の登録

1. 試合詳細ページの「動画を登録する」から YouTube の URL（または mp4 の URL）と開始位置を入力
2. 登録した内容はこのブラウザ（localStorage）に保存されます
3. フッターの「登録動画をエクスポート」で `videos.json` を出力し、中身を `js/data.js` の `videos` に貼り付けると、全員に反映されます

## 本番化に向けた次のステップ（案）

- **データベース + API**：`js/store.js` の中身を API 呼び出しに置き換える（画面側はほぼそのまま使える設計）
- **管理画面**：大会結果の入力、トーナメント表の自動作成、動画の登録・承認（ログイン付き）
- **選手写真のアップロード**
- **SEO**：選手・試合ごとの個別URLをサーバー側で描画（Next.js などへの移行を検討）
